# Self-hosted fonts

Latin WOFF2 subsets are served locally by the Receipts app. They are loaded with `font-display: swap` and covered by the adjacent SIL Open Font License texts.

- Newsreader variable, 400–600: Google Fonts family `newsreader`, Latin subset.
- Instrument Sans variable, 400–600: Google Fonts family `instrumentsans`, Latin subset.
- IBM Plex Mono, 400 and 500: Google Fonts family `ibmplexmono`, Latin subset.

Source files were retrieved from Google Fonts (`fonts.gstatic.com`) and the corresponding family license directory in `google/fonts` on GitHub. Runtime CSS does not request external font hosts.
