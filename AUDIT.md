# Receipts frontend audit — Phase 0

Date: 2026-10-29. Start commit: `e7b3efe87911118a18ae1d29c824b825dbc9369d` (`revert: restore backend to baseline, keep frontend redesign`). Branch: `fix-and-landing`.

## Served files

`run.py` starts Uvicorn with `app.main:app`; `app/main.py` sets `static_dir = BASE_DIR / "static"`, mounts it at `/static`, and serves `static/index.html` at `/`. No frontend build step is configured. The UI assets in scope are `static/index.html`, `static/css/{tokens,thermal,style}.css`, `static/js/app.js`, and assets under `static/brand` and `static/fonts`. API calls are made by the client to same-origin `/api/*` routes. The page title is the v4 title in the HTML, then updated by client routes.
